Four Earned Autonomy Levels (Per Component)

Earn it, lose it: raised only when eval pass rate & grounding clear thresholds; drops 1 level on breach.

L1 · Gate Hand-OffHigh-Risk / Prod Release

Agent suggests only; human signs off before next step (e.g., live payment release).

L2 · Human-Led + AssistDefault for Normal Build

Human drives architecture & judgement-heavy logic; agent assists in small batches.

L3 · Real-Time Co-WorkDesign, Spec & Discovery

Interactive pairing for framing Goal Contracts, UX trust specs & edge cases.

L4 · Bounded AutonomousRepeatable & Well-Tested

Agent executes inside contract bounds; human approves result (e.g., generating & running tests).

Archetype 1 · 4–5 FTE

Greenfield Build

Leads with Intent + Experience; spec-first from day 1. Default L2–L3; L4 on bounded tests.

Archetype 2 · 5–6 FTE

Brownfield Enhancement

Context Engineer leads: code graph & legacy rules are the bottleneck. L2 build; L1 on core paths.

Archetype 3 · 5–6 FTE

Modernisation / Migration

Context + Alignment lead with characterisation tests first. L3 design; L4 transforms with tests.

Archetype 4 · 3–5 FTE

Run / Support (AMS)

Alignment + Value lead via telemetry-driven intents. L4 triage; L1 production fixes.

Worked Loop Example: Duplicate-Payment Warning (Zero Ad-Hoc Prompting)

Outcome: Support tickets −27% · Drop-off flat
1. IntentWarn before likely duplicate payment; never hard-block. (Goal Contract)
2. ExperienceExplainable warning + "Pay Anyway" override. (UX Spec)
3. ContextSame payee + amount in 24h rule; no-PII logging rule. (AGENTS.md)
4. BuildDetection built at L2; tests at L4; latency 120ms (<200ms). (PR)
5. AlignZero false-block evals green; live payment at L1 Sponsor sign-off.
6. OutcomeTickets −27%; pattern banked; next intent: scheduled payments.
